# Data

Dataset files are not committed to this repository.

## Energy Efficiency Dataset

**Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/242/energy+efficiency)

**Download:** Click "Download" on the UCI page and place `ENB2012_data.xlsx` in this `data/` directory.

The notebook expects the file at `../data/ENB2012_data.xlsx` relative to the `notebooks/` folder.
